# CityMETER: Transit Thailand

**Live demo: [montri-th.github.io/transit](https://montri-th.github.io/transit/)** · [Source repository](https://github.com/montri-th/transit)

ทำเลนี้ไปถึงด้วยระบบรางได้แค่ไหน: แผนที่เมือง 3 มิติของรถไฟฟ้าและรถไฟชานเมืองที่เปิดให้บริการในกรุงเทพฯ และปริมณฑล 10 สาย จุดเปลี่ยนสาย 18 จุด และโครงการรางที่กำลังก่อสร้าง 7 โครงการ พร้อมแนวเส้นทาง อาคารของสถานีจาก OpenStreetMap และชั้นขนส่งอื่น (รถเมล์ วินมอเตอร์ไซค์ เรือ บขส./สถานีขนส่ง รถไฟทางไกล ท่าอากาศยาน) ที่เปิดได้เมื่อต้องการ ทุกสถานีมีแหล่ง วันที่ตรวจ และบทบาทของพิกัด

## ใช้งาน

```sh
npm start        # http://127.0.0.1:4173
npm test         # node --test: โมเดล ฉาก 3 มิติ และค่าคงที่ของข้อมูลที่เผยแพร่
npm run build:data -- --export <โฟลเดอร์ไฟล์ส่งออกของชีต> [--osm <osm-rail-stations-2026-10-31.json> | --osm-derived sources/osm/osm-derived-2026-10-31.json]
npm run verify:live   # เทียบไฟล์บนเว็บจริงกับ repository
```

ไม่ต้องติดตั้ง dependencies ภายในโปรเจกต์ (Node ≥ 20 สำหรับ tests/scripts, Python 3 สำหรับ server และ build ข้อมูล) แผนที่โหลด MapLibre GL 5.6.2 และ three.js 0.186.1 แบบระบุรุ่นจาก unpkg กับ OpenFreeMap vector tiles; ถ้าโหลด three.js ไม่ได้ แผนที่ยังแสดงเส้นทาง 2 มิติ หมุด และมวลอาคารได้ กราฟวาดด้วย HTML/SVG ภายในโปรเจกต์

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรกบนเมือง 3 มิติ:** หน้าแรกโฟกัสจุดเปลี่ยนสายที่เชื่อมหลายสายที่สุด (เรียงตามจำนวนสาย แล้วตามจำนวนสถานีบนสายที่มาบรรจบ) แผงขวาบอกจำนวนจุดเปลี่ยนสาย สายที่เปิด และสถานีที่กำลังก่อสร้าง “ดูทั้งหมด” เปิดทุกสายเท่ากัน
- **แนวเส้นทาง:** ริบบอนตามแนว GTFS สีตามสายจาก OpenStreetMap (ข้อยกเว้นสีที่เจ้าของอนุมัติ — §7 ของ DATA_METHOD) ยกสูงตามระดับทางจาก OpenStreetMap: ยกระดับ ระดับพื้น ใต้ดิน มีตอม่อเมื่อซูมใกล้ สายที่กำลังก่อสร้างเป็นเส้นประทั้ง 2D และ 3D สายสีส้มและสายสีม่วงใต้ใช้แนวก่อสร้างจาก OpenStreetMap (ไม่ใช่แบบทางการ) แนวที่ไม่มีแหล่งจะไม่ถูกสร้างขึ้น
- **สถานีและอาคาร:** แผ่นสถานีมีแถบสีของทุกสายที่มาบรรจบ อาคารสถานี 125 หลังจับคู่จาก OSM กดสถานีจากแผง หมุด หรือวัตถุ 3 มิติ แล้วกล้องจัดพื้นที่รัศมี 450 ม. รอบสถานีพร้อมความสูงอาคารให้พอดีส่วนที่มองเห็นของแผนที่ (“มุมสถาปนิก” pitch 75 / FOV 24 บนจอกว้าง)
- **วัตถุซ้อนกัน (raycast cycling แบบ pmndrs):** ชี้เมาส์แล้วจุดสถานะบอกว่ามีวัตถุซ้อนกันกี่ชิ้น กดซ้ำที่เดิมเพื่อสลับชิ้น — เช่น สถานียกระดับเหนือสายใต้ดิน
- **breadcrumb:** ประเทศไทย › จังหวัด › สาย › สถานี ด้วยรหัสจังหวัดแบบ CityMETER production (BKK, NBI, …); URL เก็บ `?province=BKK&line=MRT_BLUE&station=<id>`
- **แผงสาย:** สถานีเรียงตามรหัสของผู้ให้บริการ จุดเปลี่ยนสาย ผู้ให้บริการตาม GTFS ความยาวแนว; โครงการก่อสร้างแสดงขั้นงาน ความคืบหน้าระดับโครงการทุกตัวชี้วัดพร้อมงวด และเป้าหมายตามแหล่ง
- **แผงสถานี:** สายที่ผ่านและเปลี่ยนได้ การเชื่อมต่อ (ปัจจุบัน / เปลี่ยนขบวน / อนาคต / BRT) พิกัดและบทบาท ผู้โดยสาร (ARL ปี 2567, BTS ปี 2564 แยกชุด) หลักฐานงานก่อสร้าง ขนส่งอื่นรอบสถานี (จำนวนในรัศมี 500 ม. และจุดที่ใกล้สุด หรือ “นอกขอบเขตข้อมูล”) และลิงก์แหล่ง
- **กราฟ:** สถานีต่อสาย (LDS `count`), เปิดแล้ว/กำลังสร้างต่อสาย (series พร้อม shape cue), ผู้โดยสารเฉพาะชุดที่เทียบกันได้ (LDS `activity`) — ทุกแท่งเป็นปุ่ม
- **ขนส่งอื่น (ปุ่มบนแผนที่):** สายรถเมล์และ BRT (ความหนาของเส้น = จำนวน route ใน GTFS ที่ผ่านช่วงถนน), ป้ายรถเมล์และสถานี BRT, วินมอเตอร์ไซค์ กทม. 2,438 จุด, เรือ, สถานีขนส่ง 126 แห่งและจุดขึ้นรถ บขส. 31 จุด, ที่หยุดรถไฟทางไกล 176 จุด, ท่าอากาศยาน 32 แห่ง — แต่ละโหมดมีรูปทรงของตัวเอง ปิดไว้เป็นค่าเริ่มต้น โหลดเมื่อเปิด เมื่อเปิดแล้วเห็นได้ทุกระดับซูมและทุกหน้าจอ (ปุ่มชั้นที่เปิดอยู่ใต้แถบเครื่องมือ กดเพื่อซ่อน) กดจุดเพื่อดูชื่อและแหล่ง URL เก็บ `?layers=bus,stops,moto`
- จอแคบแนวตั้งใช้ bottom sheet และ Aha ย่อบนแผนที่; ธีมสว่าง/มืดใช้ค่าสีข้อมูลเดียวกัน
